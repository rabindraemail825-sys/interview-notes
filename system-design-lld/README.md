# System Design: Low-Level Design (LLD)

Notes and practice for learning LLD for interviews.

## Roadmap

### 1. Foundations
- [ ] OOP: encapsulation, abstraction, inheritance, polymorphism
- [ ] Class relationships: association, aggregation, composition, dependency
- [ ] UML class and sequence diagrams

### 2. Design principles
- [ ] SOLID
- [ ] DRY, KISS, YAGNI
- [ ] Composition over inheritance

### 3. Design patterns
- [ ] Creational: Singleton, Factory Method, Abstract Factory, Builder
- [ ] Structural: Adapter, Decorator, Facade, Proxy, Composite
- [ ] Behavioral: Strategy, Observer, State, Command, Chain of Responsibility

### 4. Concurrency
- [ ] Threads, locks and synchronization
- [ ] Producer-consumer
- [ ] Thread-safe class design

### 5. Practice problems
- [ ] Parking lot
- [ ] Vending machine
- [ ] Elevator system
- [ ] Tic-tac-toe
- [ ] Splitwise
- [ ] Library management system
- [ ] BookMyShow
- [ ] LRU cache
- [ ] Rate limiter
- [ ] Logging framework

## How to approach a problem

1. Clarify requirements and scope.
2. Identify the core entities.
3. Define their relationships and responsibilities.
4. Write the key interfaces and method signatures.
5. Apply patterns only where they solve a real need.
6. Check edge cases, concurrency and extensibility.
